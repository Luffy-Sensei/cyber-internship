# Day 04 — Vishing & Smishing Awareness Engine

## Objective

Build a Python-based social engineering awareness engine that generates
training scenarios demonstrating common vishing and smishing techniques,
psychological triggers, red flags, and defensive responses.

The engine is designed for cybersecurity awareness and security-training
purposes.

- Produce machine-readable JSON security reports.

- Associate attack indicators with defensive guidance.
- Create knowledge-check questions for security awareness training.

## Concepts

### Vishing

Vishing is voice-based phishing in which an attacker attempts to manipulate
a victim through a phone call.

Common techniques include:

- Authority impersonation
- Fear and consequences
- Urgency
- Credential requests
- Caller impersonation
- Pressure to act immediately

### Smishing

Smishing is phishing conducted through SMS or text messaging.

Common indicators include:

- Unexpected messages
- Suspicious URLs
- Sender impersonation
- Urgency
- Account-security pretexts
- Requests to click links or provide information

---

## Psychological Triggers

The engine models several common social-engineering triggers.

| Trigger | Description |
|---|---|
| Authority | Impersonating a trusted person or organization |
| Fear | Creating concern about negative consequences |
| Urgency | Pressuring the recipient to act immediately |
| Scarcity | Creating an artificial limited-time condition |
| Liking | Building rapport or friendliness to increase trust |

Defensive Lessons

The generated scenarios demonstrate several important defensive principles:

Never disclose passwords or authentication codes over unsolicited calls.
Independently verify unexpected requests.
Do not rely on caller ID as proof of identity.
Do not allow urgency to bypass verification.
Avoid clicking unexpected SMS links.
Verify account activity through official applications or websites.
Report suspicious social-engineering attempts through appropriate channels.
